# دليل مدير الصيانة

**الدور في النظام:** مدير الصيانة / مدير المراكز (صلاحية أساسية: `repair.adminDashboard.view`)  
**لمن:** من يشرف على مركز واحد موسّع أو كل مراكز الصيانة  
**الغرض:** مرجع بعد التدريب  
**آخر تحديث:** 2026-08-10

> النطاق يُضبط من **إعدادات الصيانة**: فرع واحد أو **كل مراكز الصيانة**.  
> اسم الدور قد يكون «مدير الصيانة» أو «مدير مراكز» — العبرة بالصلاحيات والربط بالفروع.

---

## 1) شغلك باختصار

أنت تشرف على تشغيل الصيانة: الطلبات، الأداء، التموين، المال، والجودة عبر الفرع/المراكز — مش بديل عن الفني في الورشة ولا عن كل تفاصيل استقبال كل ساعة (إلا لو شغّلت مركز بنفسك).

| تفعل أنت | تفوّض / تتابع |
|----------|----------------|
| لوحة أدمن الصيانة والمؤشرات | تسجيل كل طلب يوميًا (الاستقبال) |
| متابعة الطلبات عبر الفروع المسموحة | التشخيص الفني التفصيلي |
| أداء الفنيين | طلب القطع من الورشة |
| متابعة التموين بين المركزي والمراكز | تأكيد استلام كل شحنة (الاستقبال) |
| الخزينة وتقاريرها (إن مُنحت) | |
| الفروع والإعدادات (إن مُنحت) | |
| اعتمادات حساسة (خصم/آجل/عكس…) حسب الصلاحية | |

**أول صفحة بعد الدخول:**  
`لوحة الصيانة` → `/repair` (لوحة الإدارة عند وجود صلاحية الأدمن)

من الموبايل (مدير مراكز): **الرئيسية** · **الطلبات** · **التموين** · **الأداء**.

## 3) مسار العمل اليومي / الأسبوعي

### يوميًا (15–25 د)
1. افتح **لوحة الصيانة** — المتأخرات والجاهز للتسليم والاختناقات.  
2. راجع **الطلبات** الحرجة (SLA / شكاوى / انتظار قطع طويل).  
3. راجع **التموين** المعلّق (اعتماد/تجهيز/استلام).  
4. راجع **التحصيل** المعلّق ومخاطر العهدة.  
5. نظرة سريعة على **أداء الفنيين** (تراكم أو فراغ).

### أسبوعيًا
- [ ] مقارنة أداء المراكز/الفنيين  
- [ ] تقرير خزينة / فروقات  
- [ ] شكاوى متكررة وموديلات عالية العطل  
- [ ] جاهزية ربط الفروع بالمخازن  

### شهريًا
- [ ] تقرير خزينة شهري  
- [ ] مراجعة سياسات الخصم/الآجل/الضمان  
- [ ] مراجعة إعدادات النطاق (فرع vs كل المراكز)  

---

## 4) فرقك ومن يعمل ماذا

| الدور | المسؤولية |
|-------|-----------|
| استقبال / مسؤول مركز | طلب جديد، تحصيل، تموين واستلام، صرف قطع، عهدة |
| فني صيانة | تشخيص وإصلاح من مساحة الورشة |
| مخزن قطع مركزي | تجهيز تموين المراكز |
| مدير الصيانة (أنت) | رقابة، أداء، اعتمادات، إعدادات، حل الاختناقات |

---

## 5) صلاحيات حساسة (راجع حسابك)

قد تختلف حسب الدور المخصص. الشائع لمدير الصيانة:

- `repair.adminDashboard.view` — لوحة الإدارة  
- `repair.technician.view` — أداء الفنيين  
- `repair.branches.manage` و/أو نطاق «كل المراكز» من الإعدادات  
- `repair.treasury.view` / `manage`  
- `repair.settings.manage`  
- اعتماد خصم/آجل/عكس دفعات إن مُنحت  

**مهم:** لو مش شايف مركز معيّن — راجع ربط الفروع في المستخدم + إعداد نطاق المدير.

---

## 6) أخطاء شائعة

| الخطأ | الصحيح |
|-------|--------|
| النزول للتشخيص بدل حل الاختناق | فوّض الورشة وركّز على التأخير والتموين والتحصيل |
| تجاهل تموين معلّق | الرصيد مش بيدخل المركز إلا بعد استلام الاستقبال |
| مقارنة فنيين بدون نفس نوع الطلبات | استخدم لوحة الأداء مع فلترة الفرع/الفترة |
| تغيير إعدادات بدون إبلاغ المراكز | وثّق التغيير (نطاق، موافقات، ضمان) |

---

## 7) قائمة تحقق تدريب

- [ ] فتح لوحة أدمن وشرح المؤشرات  
- [ ] فلترة الطلبات حسب فرع/حالة  
- [ ] متابعة تموين من الطلب حتى الاستلام  
- [ ] قراءة أداء فني واتخاذ إجراء  
- [ ] فتح خزينة/تقرير (إن مفعّل)  
- [ ] مراجعة فرع واحد في شاشة الفروع  
- [ ] معرفة أين يُضبط نطاق المدير في الإعدادات

## 8) لمن تلجأ

| المشكلة | لمن |
|---------|-----|
| تموين مركزي متوقف | مخزن قطع الغيار المركزي |
| صلاحيات/فروع | مدير النظام |
| محاسبة/ترحيل | المحاسبة |
| عطل تقني | الدعم الفني |

**خلاصة:** لوحة الإدارة كل صباح → الطلبات الحرجة → التموين → التحصيل → أداء الفنيين → إعدادات عند الحاجة.
