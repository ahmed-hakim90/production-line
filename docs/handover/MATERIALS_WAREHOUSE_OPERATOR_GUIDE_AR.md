# دليل مسؤول مخزن مستلزمات الإنتاج

**الدور في النظام:** مسؤول مخزن المستلزمات  
**لمن:** الموظف المسؤول عن مخزن المكونات / المستلزمات  
**الغرض:** مرجع بعد التدريب — يفتحه ويعرف كل صفحة وشغله اليومي  
**آخر تحديث:** 2026-08-10

---

## 1) شغلك باختصار

أنت مسؤول عن **مخزن المستلزمات (المكونات)** من الاستلام حتى الصرف للإنتاج، مع متابعة الأرصدة والتنبيهات والجرد.

| تفعل أنت | لا تفعل أنت (عادة) |
|----------|---------------------|
| استلام مكونات واردة | تقارير إنتاج الخطوط |
| صرف للإنتاج واعتماد طلبات الصرف | تحكم التغليف |
| تحويلات من/إلى مخزن المستلزمات | اعتماد وارد الإنتاج النهائي |
| جرد ومطابقة المستلزمات | إدارة قطع غيار مراكز الصيانة (إلا لو طُلب منك) |
| صرف مستهلكات الأقسام | إنشاء خطط الإنتاج |
| متابعة نقص المكونات | |

**أول صفحة بعد الدخول:**  
`مساحة مستلزمات الإنتاج` → `/inventory/raw-materials/control`

لو الصفحة قالت إن المخزن غير محدّد: اطلب من الإدارة تعيين مخزن المستلزمات من **الإعدادات → توجيه المخزون**.

### هـ) صفحات تظهر في القائمة لكن ليست شغلك الأساسي

| الصفحة | ملاحظة |
|--------|--------|
| إذن صرف للمراكز (تموين) | أقرب لمخزن قطع الغيار — استخدمها فقط لو طُلب منك |
| فاتورة شراء قطع / إذن إضافة قطع / أرصدة المراكز / سحب من المراكز | ليست مسار مستلزمات الإنتاج اليومي |

### و) صفحات مخفية عن دورك عمدًا

- تحكم التغليف  
- اعتمادات وارد الإنتاج  
- تحليل استهلاك الإنتاج  

لو احتجتها: ترفع الطلب للإدارة / مدير المصنع.

## 3) مسار العمل اليومي (احفظه)

### صباحًا (10–15 دقيقة)

1. افتح **مساحة مستلزمات الإنتاج**.
2. راجع أرقام اللوحة: أصناف، كمية، تنبيهات، معلّقات.
3. افتح **تنبيهات المستلزمات** — عالج الناقص/النافد أو بلّغ المشتريات.
4. راجع **اعتماد تحويلات** و**صرف للإنتاج** لأي طلب معلّق.

### خلال اليوم (حسب الطلب)

| الحالة | ماذا تفعل | أين |
|--------|-----------|-----|
| وصلت بضاعة مكونات | استلام مستلزمات (أو وارد يدوي) | استلام / حركات وارد |
| الإنتاج يطلب مكونات | راجع الطلب → اعتمد/صرّف → اطبع | صرف للإنتاج |
| نقل لمخزن أو موقع آخر | تحويل ثم تابع الاعتماد إن لزم | تحويل + اعتماد تحويلات |
| قسم يطلب مستهلكات | أنشئ/صرف مستهلكات | مستهلكات الأقسام |
| شك في الرصيد | كارت الصنف + الحركات | كارت الصنف / الحركات |

### نهاية اليوم (5 دقائق)

- [ ] لا طلبات صرف معلّقة بدون قرار  
- [ ] لا تحويلات معلّقة بدون اعتماد/رفض  
- [ ] لا رصيد سالب جديد بدون سبب معروف  
- [ ] الاستلامات المنفّذة اليوم ظاهرة في الحركات  

---

## 4) شرح أهم شاشتين بالتفصيل

### 4.1 مساحة مستلزمات الإنتاج

هذه **لوحة التشغيل**. منها أزرار مباشرة:

1. **الأرصدة** — ماذا عندك الآن  
2. **استلام مكونات** — وارد  
3. **صرف** — طلبات الإنتاج + صرف يدوي  
4. **تحويل** — نقل + اعتماد  
5. **جرد ومطابقة**  
6. **الحركات** — آخر ما تم  

أسفل الصفحة: **المتاح للتجميع حسب المنتج** (كم منتج يمكن تجهيزه من الرصيد الحالي). هذا مساعد تخطيط — ليس بديلًا للجرد.

### 4.2 صرف للإنتاج

المسار الطبيعي:

1. يظهر طلب صرف من الإنتاج (خطة/أمر شغل)  
2. تراجع الكميات والمخزن  
3. تعتمد / تجهّز حسب صلاحيتك  
4. تنفّذ الصرف  
5. تطبع إذن الصرف عند الحاجة  

**قاعدة ذهبية:** الصرف المرتبط بالإنتاج يكون من شاشة **صرف للإنتاج** وليس صرفًا يدويًا عشوائيًا — حتى يبقى الربط مع الخطة/الأمر واضحًا.

## 5) مفاهيم لازم تفهمها

| المصطلح | المعنى البسيط |
|---------|----------------|
| مخزن المستلزمات | مخزن المكونات المستخدمة في التصنيع |
| رصيد | الكمية الحالية لصنف في مخزن |
| حركة وارد (IN) | دخول كمية للمخزن |
| حركة صرف (OUT) | خروج كمية من المخزن |
| تحويل (TRANSFER) | نقل بين مخزنين/مواقع دون «بيع» |
| جرد | عدّ فعلي ومقارنة بالنظام وتسوية الفرق |
| تنبيه نقص | الرصيد وصل للحد الأدنى أو أقل |
| رصيد سالب | خطأ تشغيلي — راجعه فورًا |
| كارت الصنف | سجل حياة الصنف (كل حركاته) |
| مستهلكات أقسام | أصناف تُصرف للإدارات (ليست بالضرورة BOM منتج) |

---

## 6) صلاحياتك (باختصار)

دورك يسمح عادةً بـ:

- عرض المخازن والأرصدة والحركات  
- إنشاء/تعديل/طباعة/تصدير حركات  
- جرد ومواقع وأصناف ضمن نطاقك  
- اعتماد تحويلات  
- تفكيك عكسي  
- صرف إنتاج (إنشاء / اعتماد / طباعة / مرتجع / تعويض حسب المنح)  
- مستهلكات الأقسام كامل الدورة  
- عرض المواد والتخطيط وفجوة الشراء ودورات التوريد  

**مهم:** ما يظهر في القائمة يعتمد على صلاحيات حسابك. لو زر ناقص — اطلب من مدير النظام مراجعة الدور، لا تحاول تجاوز الشاشة.

## 7) أخطاء شائعة وتجنّبها

| الخطأ | الصحيح |
|-------|--------|
| صرف يدوي بدل صرف الإنتاج | استخدم **صرف للإنتاج** للطلبات الرسمية |
| نسيان اعتماد التحويل | راقب **اعتماد تحويلات المخازن** يوميًا |
| إدخال وارد بدون مراجعة الصنف/الكمية | راجع الكود والوحدة قبل الحفظ |
| تجاهل التنبيهات | النقص اليوم يصبح توقف خط غدًا |
| الجرد بدون قفل/مطابقة واضحة | نفّذ الجرد من شاشته واتبع فروقات التسوية |
| الاعتماد على الذاكرة بدل كارت الصنف | افتح كارت الصنف عند أي خلاف |

## 8) قائمة تحقق تدريب (يوقّع عليها بعد الشرح)

### اليوم الأول — فهم ومشاهدة

- [ ] فتح مساحة مستلزمات الإنتاج وشرح أرقام اللوحة  
- [ ] فتح تنبيهات المستلزمات  
- [ ] فتح أرصدة + كارت صنف + حركات  
- [ ] مشاهدة طلب صرف إنتاج من الألف للياء  

### اليوم الثاني — تنفيذ تحت إشراف

- [ ] تنفيذ استلام مستلزمات حقيقي أو تجريبي  
- [ ] اعتماد/صرف طلب إنتاج وطباعة  
- [ ] عمل تحويل ومتابعة الاعتماد  
- [ ] فتح جرد وفهم خطوات المطابقة  
- [ ] صرف مستهلكات قسم (إن مستخدمة في المصنع)  

### جاهزية العمل منفردًا

- [ ] يعرف نقطة البداية كل صباح  
- [ ] يعرف فرق صرف الإنتاج عن الصرف اليدوي  
- [ ] يعرف لمن يبلّغ عند نقص حاد أو رصيد سالب  
- [ ] استلم هذا الدليل مطبوعًا أو على الجهاز
