# دليل مسؤول مخزن قطع الغيار المركزي

**الدور في النظام:** مسؤول مخزن قطع الغيار المركزي (`spare_parts_central_warehouse`)  
**لمن:** أمين المخزن المركزي لقطع غيار الصيانة  
**الغرض:** مرجع بعد التدريب  
**آخر تحديث:** 2026-08-10

---

## 1) شغلك باختصار

أنت مخزن **قطع الغيار المركزي**. تستقبل طلبات تموين من مراكز الصيانة، تعتمد/تجهّز، وتتابع السحب من المراكز.  
**الرصيد لا يخرج فعليًا للمراكز إلا بعد ما المركز يؤكّد الاستلام.**

| تفعل أنت | لا تفعل أنت (عادة) |
|----------|---------------------|
| اعتماد طلبات التموين من المراكز | تسجيل طلب صيانة عميل |
| تجهيز الطلب من رصيدك المركزي | تأكيد استلام التموين في المركز (للاستقبال) |
| موافقة المسؤول بعد التجهيز (إن مُنحت) | تشخيص فني / مساحة الورشة |
| سحب قطع من المراكز (إنشاء/تأكيد/إلغاء) | صرف سند قطع على طلب صيانة (للاستقبال) |
| أرصدة المراكز + وارد/جرد المخزن المركزي | إدارة فروع الصيانة والإعدادات |
| حركات وأرصدة ومواقع ضمن نطاقك | |

**أول صفحة بعد الدخول (مربوط بمخزن `spare_parts_central`):**  
`إذن صرف للمراكز (تموين)` → `/inventory/spare-parts-replenishment`

**تهيئة مهمة:** من إدارة المستخدمين اربط الحساب بمخزن دوره **قطع غيار (مركزي)**.

---

## 2) دورة التموين (احفظها)

```
طلب من المركز → اعتماد → تجهيز (مركزي) → موافقة المسؤول → استلام المركز
```

| الخطوة | من يفعل | هل يتحرك الرصيد؟ |
|--------|---------|------------------|
| طلب | مركز الصيانة (استقبال) | لا |
| اعتماد | أنت / مخوّل الاعتماد | لا |
| تجهيز | أنت (المخزن المركزي) | لا بعد |
| موافقة المسؤول | أنت إن مُنحت | لا |
| تأكيد الاستلام | المركز | **نعم** — تحويل من المركزي → المركز |

## 4) مسار العمل اليومي

### صباحًا (10–15 د)
1. افتح **تموين قطع الغيار (مركزي → مراكز)**.  
2. صفّ الطلبات: بانتظار اعتماد → بانتظار تجهيز → بانتظار موافقة مسؤول.  
3. راجع **أرصدة المراكز** للأصناف الحرجة.  
4. راجع **سحب من المراكز** المعلّق.

### خلال اليوم
| الحالة | ماذا تفعل | أين |
|--------|-----------|-----|
| طلب تموين جديد من مركز | راجع الكميات والرصيد → اعتمد | تموين مركزي |
| طلب معتمد | جهّز الأصناف من المخزن | تموين مركزي (تجهيز) |
| بعد التجهيز | موافقة المسؤول إن لزم | تموين مركزي |
| المركز استلم | لا تحتاج فعل — الرصيد يتحرك عند استلامهم | راقب الحالة `received` |
| زيادة رصيد في مركز بدون داعي | أنشئ سحب للمركزي | سحب من المراكز |
| وارد شراء | فاتورة شراء قطع أو وارد يدوي | شراء / حركات وارد |

### نهاية اليوم
- [ ] لا طلبات معتمدة من غير تجهيز بدون سبب  
- [ ] لا طلبات مجهّزة معلّقة عندك من غير موافقة (إن مطلوبة)  
- [ ] حالات السحب المعلّقة متابَعة  
- [ ] الحركات اليومية منطقية على كارت الصنف عند الشك  

---

## 5) قواعد ذهبية

1. **الاستلام عند المركز = لحظة خصم رصيدك** — قبل كده الطلب مراحل موافقات فقط.  
2. جهّز من الرصيد الفعلي؛ متوعدش مركز بكمية مش موجودة.  
3. فرّق بين **تموين (مركزي → مركز)** و**سحب (مركز → مركزي)**.  
4. تكلفة الشراء على بيانات المواد مركزياً — المراكز تشوف سعر الاستخدام/البيع في الصيانة.  
5. لو الحساب مش مربوط بمخزن مركزي، هتشوف نطاق أوسع أو مسار مختلف — ثبّت الربط مع الإدارة.

---

## 6) أخطاء شائعة

| الخطأ | الصحيح |
|-------|--------|
| اعتبار الاعتماد = خروج رصيد | الرصيد عند **استلام المركز** |
| تجهيز بدون مراجعة الرصيد | راجع الأرصدة قبل التجهيز |
| استخدام شاشة تموين الصيانة بدل شاشة المخازن | أنت تستخدم `/inventory/spare-parts-replenishment` |
| نسيان متابعة السحب من المراكز | راقب شاشة السحب يوميًا |
| خلط مستلزمات الإنتاج مع قطع الغيار | مسار مختلف تمامًا |

## 8) لمن تلجأ

| المشكلة | لمن |
|---------|-----|
| مركز طالب كمية مش موجودة | المشتريات / مدير الصيانة |
| مركز ما أكّدش الاستلام | مسؤول المركز / الاستقبال |
| صلاحية اعتماد/تجهيز ناقصة | مدير النظام |
| مخزن مش مربوط على الحساب | مدير النظام |
| عطل تقني | الدعم الفني |

**خلاصة:** تموين مركزي كل صباح → اعتمد → جهّز → تابع الاستلام من المركز → راقب أرصدة المراكز والسحب.
