# دليل مسؤول مركز الصيانة (استقبال)

**الدور في النظام:** استقبال صيانة (`repair_reception`) — تشغيل المركز يوميًا  
**لمن:** مسؤول المركز / موظف الاستقبال في فرع صيانة  
**الغرض:** مرجع بعد التدريب  
**آخر تحديث:** 2026-08-10

> ملاحظة: في النظام، **استقبال المركز** هو اللي بيشغّل الفرع (طلبات + تحصيل + تموين + صرف قطع).  
> دور «مسؤول مخزن مركز صيانة» منفصل نادرًا ويُستخدم لو فصلت المخزن عن الاستقبال.

---

## 1) شغلك باختصار

أنت واجهة المركز مع العميل وتشغيل الطلب من الاستلام حتى التسليم، مع مخزون قطع المركز.

| تفعل أنت | لا تفعل أنت (عادة) |
|----------|---------------------|
| تسجيل طلب جديد واستلام جهاز | إعدادات كل المراكز / الفروع العامة |
| متابعة طلبات فرعك | لوحة أدمن كل المراكز |
| التحصيل والتسليم | اعتمادات خصم/آجل على مستوى الإدارة (إلا لو مُنحت لك) |
| عهدة أجهزة العملاء | شغل الورشة الفني (تشخيص عميق) |
| تموين قطع المركز واستلامها | تجهيز التموين من المخزن المركزي |
| سندات صرف قطع الغيار للورشة | إدارة خزينة كل الشركة |
| استبدال / شكاوى على مستوى الفرع | |

**أول صفحة بعد الدخول:**  
`لوحة الصيانة` → `/repair` (أو الرئيسية `/`)

من الموبايل: **الرئيسية** · **طلب جديد** · **الطلبات** · **التحصيل**.

**تهيئة مهمة:** اربط الحساب بـ **فرع الصيانة** (+ مخزن مركز الصيانة إن وُجد).

## 2) خريطة الصفحات الخاصة بك

| الصفحة | المسار | الاستخدام |
|--------|--------|-----------|
| قطع غيار المراكز | `/repair/parts` | أرصدة قطع المركز |

- تموين المركزي من جهة التجهيز (`prepare`) — ده المخزن المركزي

## 3) مسار العمل اليومي

### صباحًا (10–15 د)
1. افتح **لوحة الصيانة**.  
2. راجع الطلبات المتأخرة والجاهزة للتسليم.  
3. راجع **التحصيل** المعلّق و**تموين** بانتظار الاستلام.  
4. راجع **سندات صرف** القطع المعلّقة للفنيين.

### خلال اليوم
| الحالة | ماذا تفعل | أين |
|--------|-----------|-----|
| عميل جديد | سجّل طلب + بيانات الجهاز/الضمان | طلب جديد |
| جهاز للتشخيص | أسند فنيًا من قائمة الفرع (مش «إسناد لي»)؛ لو الفني غايب: فك الإسناد أو غيّر الفني | الطلبات / تفاصيل الطلب |
| فني طلب قطع | أنشئ/نفّذ سند صرف بعد التوفر | سندات صرف قطع |
| نقص قطع | اطلب تموين من المركزي | متابعة التموين |
| وصل تموين | أكّد الاستلام (هنا يدخل الرصيد) | متابعة التموين |
| جاهز للتسليم | حصّل (إن لزم) وسلّم | التحصيل والتسليم |
| غير قابل للإصلاح | أكمل إجراءات العهدة مع العميل | عهدة الأجهزة |

### نهاية اليوم
- [ ] لا أجهزة جاهزة من غير تسليم/إبلاغ عميل  
- [ ] لا تموين واصل من غير تأكيد استلام  
- [ ] لا سند صرف معلّق بدون سبب  
- [ ] التحصيلات المسجّلة اليوم سليمة  

---

## 4) دورة حياة الطلب (باختصار)

```
استلام → إسناد (جاري الفحص) → تم الفحص → موافقة عميل (إن لزم) → قطع → إصلاح → جاهز → تحصيل/تسليم
```

**قاعدتان مهمتان:**
1. الرصيد يدخل مخزن المركز عند **تأكيد استلام التموين** فقط — مش عند إنشاء الطلب.  
2. صرف القطعة للورشة من **سندات صرف قطع الغيار** مربوط بالطلب.

---

## 5) أخطاء شائعة

| الخطأ | الصحيح |
|-------|--------|
| اعتبار طلب التموين = دخول رصيد | الرصيد بعد **تأكيد الاستلام** |
| صرف قطع بدون سند | استخدم سندات صرف القطع |
| نسيان إسناد الفني | أسند من قائمة الفرع، أو خلّي الفني يمسح QR (مش محتاج يكون مربوط بالفرع) |
| الفني مش موجود / مش في الفرع النهاردة | من تفاصيل الطلب: **تغيير الفني** أو **فك الإسناد** ثم الفني الجديد يمسح QR الكارت (أي فني في الشركة) |
| فك الإسناد أثناء الفحص بدون تشخيص | الحالة ترجع **وارد** عشان فني تاني ياخد الطلب نظيف |
| الضغط على «إسناد لي» من الاستقبال | الزر يختفي لغير الفني؛ اختر الفني من القائمة ثم احفظ |
| تحصيل قبل ما الجهاز جاهز | التزم مسار الجاهزية ثم التحصيل/التسليم |
| فتح كل المراكز | نطاقك فرعك فقط — إلا لو مُنح لك غير كده |

---

## 6) قائمة تحقق تدريب

- [ ] تسجيل طلب جديد كامل  
- [ ] إسناد فني من قائمة الفرع (بدون «إسناد لي») ومتابعة الحالة  
- [ ] فك الإسناد / تغيير فني ثم إعادة الاستلام عبر QR  
- [ ] طلب تموين + تأكيد استلام  
- [ ] سند صرف قطع لطلب  
- [ ] تحصيل وتسليم  
- [ ] عهدة / استبدال (حسب سياسة المركز)

## 7) لمن تلجأ

| المشكلة | لمن |
|---------|-----|
| تموين متأخر من المركزي | مخزن قطع الغيار المركزي / مدير الصيانة |
| صلاحيات / فرع مش مربوط | مدير النظام |
| خصم أو آجل يحتاج موافقة أعلى | مدير الصيانة |
| عطل تقني | الدعم الفني |

**خلاصة:** طلب جديد → متابعة الطلبات → تموين/صرف قطع → تحصيل وتسليم.
