# Design System — 🏭 Factory — نظام إدارة الإنتاج

Detected implementation: **React and Tailwind CSS**.

Build from the existing identity toward a modern, premium, minimal, calm, product-specific system. Avoid generic templates, excessive cards/gradients/shadows/radii, oversized type, arbitrary decoration, and blind cloning.

## Tokens and foundations

Centralize semantic color (background/surface/foreground/muted/border/primary/info/success/warning/destructive), spacing (prefer 4/8/12/16/20/24/32/40/48/64), typography roles, radii, elevation, motion, breakpoints, containers, z-index, and component sizing. New values must reuse or enter the system; document justified exceptions.

Use professional Arabic typography where relevant and CSS logical properties for first-class RTL. Start at 320–375px, validate 390–430px, tablet, laptop, and large desktop. Preserve visible focus, contrast, keyboard use, practical 44px touch targets, reduced motion, and layout stability.

## Governance

Reuse before create. Search cross-page usage before any variant or shared change. Reference material informs hierarchy, density, spacing, and interaction; it is not a clone instruction.
