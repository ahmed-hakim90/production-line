Service centers

موديول الصيانة (Repair)

مسار أعمال كامل للمراكز: استلام جهاز → تشخيص → تقدير → موافقة → إصلاح/قطع → تحصيل → تسليم — مع خزينة وتموين وضمان شركة.

ماذا يفعل؟

إدارة طلبات الصيانة، مساحة عمل الفني، قطع غيار المراكز، سندات الصرف، التحصيل، الخزينة، الاستبدال، وعهدة أجهزة العملاء.

قيمة للأعمال

يغلق الفجوة بين الورشة والمخزن والخزنة: كل طلب له حالة، مسؤول، قطع، ومبلغ — قابل للتتبع والطباعة والمشاركة.

من يستخدمه؟

استقبال، فني، مدير مركز، مدير صيانة، مخزن قطع مركزي (تموين)، وعميل عبر البوابة.

دورة حياة الطلب

استلام← إسناد / QR← تشخيص← تقدير← موافقة عميل← إصلاح← تحصيل← تسليم

الضمان: خطوط تحت ضمان الشركة قد تُغلق بمسار WAR-… بدون تحصيل؛ الخطوط خارج الضمان تُفوتر فقط.

صور فعلية

تُحدَّث عبر npm run showcase:screens. إن وُجدت اللقطات تظهر مباشرة؛ وإلا يظهر إطار يوضح الشاشة المستهدفة.

أدلة تشغيل مطبوعة جاهزة للأدوار: فني، مسؤول مركز، مدير صيانة، ومخزن قطع مركزي — داخل docs/handover/.

البيانات بين المراكز والمخزن

  • كل طلب صيانة حالة + فرع + فني + قطع + مبالغ — قابل للتدقيق.
  • رصيد قطع المركز لا يزيد إلا عند استلام التموين (مش عند إنشاء الطلب).
  • لوحة الأدمن تجمع فروع متعددة (KPIs + طوابير تأخير + مقارنة مراكز).
  • مناسب لشبكة مراكز مع ~100 مستخدم وآلاف العملاء — التفاصيل في البيانات والتحمل.
