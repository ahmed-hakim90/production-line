# عقد ظهور المتابعة والتحليل — موديول الصيانة

آخر تحديث: 2026-08-12

كل شاشة تجاوب على **سؤال واحد**. القوائم تعرض إشارات قرار فقط؛ التفاصيل العميقة داخل تفاصيل الطلب.

## مصادر الحقيقة

| طبقة | شاشة | السؤال | مصدر الحقيقة |
|------|------|--------|--------------|
| ورشة | طلبات الصيانة | الجهاز فين في المسار؟ | `RepairJob.status` + إسناد + استحقاق + عمر الطلب المفتوح |
| مخزون أجهزة | عهدة / غير قابل | إيه اللي لسه عندنا فعليًا؟ | `RepairCustodyRecord` + إثراء `jobStatus` |
| فلوس وتسليم | تحصيل وتسليم | ينفع يسلّم؟ واتدفع إيه؟ | أذونات الدفع + حالة الطلب `ready` (+ جاهز منذ) |
| استبدال | طلبات الاستبدال | الاعتماد وقف فين؟ | `RepairReplacementRequest.status` |
| مدخلات | طلبات العملاء / شكاوى | الطلب/الشكوى فين؟ | حالة الطلب/الشكوى |
| قطع | صرف قطع / تموين | التوريد وقف فين؟ | حالة الصرف/التموين |
| تحليل | لوحة الصيانة / أدمن / أداء فنيين | وين الاختناق؟ | تجميع من الطبقات فوق |

## يظهر / لا يظهر

### عهدة أجهزة العملاء (`/repair/custody-stock`)

**يظهر:** منتج، عميل/إيصال، مركز، حالة الطلب، رصيد، مدة البقاء، دخول، إجراءات.  
في تبويب غير القابل: **سبب عدم الإصلاح**.  
فلاتر: مركز، حالة، مدة البقاء (`?age=7|14` للربط من اللوحات).

**لا يظهر:** فني، تكلفة، مدفوع، تشخيص، قطع، سجل الحالات.

### طلبات الصيانة (`/repair/jobs`)

**يظهر:** إيصال، عميل، جهاز، فني، فرع، حالة، **عمر (للمفتوح)**، تكلفة، استحقاق، إجراء.  
فلتر متأخر عن الاستحقاق موجود (`focus=overdue`).

**لا يظهر:** رصيد العهدة، تفاصيل الدفع.

### تحصيل وتسليم (`/repair/payments`)

**يظهر:** طوابير الجاهزية/التحصيل/الذمم، مبالغ الإذن، **جاهز منذ** عند توفر `statusHistory` أو `updatedAt`.

**لا يظهر:** تشخيص/قطع.

### اللوحات

- لوحة الصيانة: KPIs عهدة +7/+14 قابلة للنقر → العهدة بنفس الفلتر؛ جاهز ولم يُسلَّم → التحصيل.
- لوحة الأدمن: أرقام حية (وحدات عهدة، غير قابل، +7، +14، استبدال معلّق) داخل بطاقة العملاء والعهدة.
- أداء الفنيين: ورشة فقط — بلا أرصدة عهدة.

## قاعدة ذهبية للوكلاء

لا تنسخ نفس الأعمدة لكل جدول. أضف عمودًا فقط إن كان يجيب على سؤال الشاشة أو يفعّل قرارًا فوريًا.

**حدود الموديول:** كل تشغيل مخزن المركز (قطع / تموين / جرد / تأكيد سحب) من قائمة الصيانة فقط؛ مجموعة المخازن للمركزي/المصنع — بدون تكرار شاشات.
